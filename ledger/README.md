# Contract ledger

In progress.

This part turns Prozorro data into a ledger of road repairs in Chernivtsi and matches a defect photo against it.

- **Contract ledger:** road repair contracts from Prozorro, with street, completion date, contractor, and warranty period.
- **Matching:** the photo's geolocation gives the street; the system finds the latest repair there and checks whether the warranty is still active.
